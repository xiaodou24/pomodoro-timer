# 🐱 猫咪主题番茄钟｜公考学习计时器
静态网页番茄钟，浏览器直接打开使用，无需安装。

## ✨ 功能清单
- ✅ 正向计时 / 反向倒计时两种计时模式
- ✅ 两套猫咪背景图片可切换
- ✅ 自定义录入学习任务
- ✅ 自动统计本周、本月累计学习时长
- ✅ 可选多种白噪音作为背景音
- ✅ 心得感悟记录区域，随时记录备考感受
- ✅ 全部数据保存在浏览器本地，不上传云端服务器

## 📖 使用须知
1. 访问网页链接即可使用，电脑、手机浏览器都支持
2. 学习记录存储在当前浏览器缓存：**清除浏览器缓存、无痕窗口、更换设备，记录会全部丢失**
3. 微信内置浏览器存在音频限制，白噪音无法播放时，复制链接，使用手机自带浏览器打开
4. 纯静态页面，无后端服务，不会产生任何额外费用

## 💡 项目说明
本项目为纯静态前端网页，没有调用任何AI接口。
适合公考、雅思等备考的时间管理，也可用于日常学习打卡。
